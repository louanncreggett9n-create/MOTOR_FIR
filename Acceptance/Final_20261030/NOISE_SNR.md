# P0 noise, SNR and ENOB measurement record

Date: 2026-10-30

## Scope

Measured path: AD7606 AIN_V1 -> FPGA 25.6 kSPS chain -> N1 800 SPS diagnostic output -> UART -> PC capture.

This is the N1 800 SPS, 100 Hz-centered diagnostic path. It is not an AD7606 die-only ENOB measurement. ENOB includes the analog input path, AD7606 conversion, FIR chain, N1 output channel, UART framing, and capture/analysis path.

## 100 Hz sine

Capture file: `captures/sine100_n1_20261030.csv`

The 60-second capture contained 19 checksum-failed frames. Two non-overlapping 4096-sample windows were selected as clean windows, using the criterion that the window contains no detected sample discontinuity and its residual is far below the fundamental. Both windows gave consistent results.

| Window | Samples | Fundamental | Fundamental peak | Residual RMS | SNR | SINAD | THD | ENOB at test amplitude | Full-scale-normalized ENOB |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 14336 | 4096 | 100.00644 Hz | 5208.40 LSB | 1.434 LSB | 68.19 dB | 68.19 dB | -97.37 dB | 11.03 bit | 13.69 bit |
| 28672 | 4096 | 100.00643 Hz | 5211.21 LSB | 1.476 LSB | 67.95 dB | 67.95 dB | -103.92 dB | 10.99 bit | 13.65 bit |

Conservative result from the two windows:

```text
SNR      >= 67.95 dB
SINAD    >= 67.95 dB
THD       <= -97.37 dB
ENOB at test amplitude >= 10.99 bit
Full-scale-normalized ENOB >= 13.65 bit
```

The full-scale-normalized value is an extrapolation from the measured 5.21 kLSB peak amplitude to 32768 LSB peak. It must not be presented as a directly measured full-scale ENOB without that qualification.

Independent shorted-noise cross-check:

```text
SNR from fundamental RMS / shorted-input noise RMS = 72.19 dB
```

The lower sine-residual SNR of 67.95 dB is used as the conservative report value.

## Formula

```text
ENOB = (SINAD - 1.76) / 6.02
```

## Limitations

- Results cover the N1 800 SPS path at 100 Hz, not the full 25.6 kSPS ADC bandwidth.
- The sine result uses clean 4096-point windows because the UART capture had occasional dropped frames.
- The test was performed with the F407/TPC116S4 signal source and the project AD7606 board, not with a calibrated laboratory source.
- The full-scale-normalized ENOB is an extrapolation from the measured amplitude.
